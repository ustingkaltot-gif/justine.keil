# Portfolio Website

## How to publish on GitHub Pages
1. Create a new repository on GitHub named `YOUR-USERNAME.github.io` (public).
2. Upload all files and folders from this project (index.html, style.css, script.js, resume.pdf, certificates/).
3. Go to Settings > Pages > Source: "Deploy from a branch" > Branch: `main` / root > Save.
4. After 1-2 minutes your site is live at https://YOUR-USERNAME.github.io

## Before you publish
- Replace the email, GitHub, and LinkedIn links in index.html.
- Add your certificate images in /certificates and edit the list in script.js.
- Add resume.pdf to the main folder (remove phone number, birth date, and home address first).
